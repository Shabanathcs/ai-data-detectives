Field is a column heading. It tells you what is stored, like Name or Age.
Record is one row. It has all the facts about one person.
Dataset is the whole table, all records together.

Mission 1 · Clean the Data Clean

A class survey has 5 mistakes hiding in it. Find them all!

Impossible valueA number that cannot be true
Missing valueA box left empty
Spelling mistakeA word typed wrongly (2 of these)
DuplicateThe same row typed twice
How to play
  1. Tap a cell you think is wrong. It turns yellow.
  2. For the duplicate, tap any cell in the repeated row.
  3. Tapped by mistake? Tap again to undo.
  4. Press Check.

Cells marked: 0 / 5

Look at the Age column: can an 11-year-old be 112? Then compare Row 3 and Row 7 carefully. Read every emirate and fruit name slowly.
  • Yusuf, Age 112: impossible for a Grade 6 student.
  • Kabir, "Dubaii": spelling mistake. It should be "Dubai".
  • Ishaan, Emirate empty: missing value.
  • Row 7, Rohan: duplicate. It is the same as Row 3.
  • Hamdan, "Mnago": spelling mistake. It should be "Mango".
Solved!

Mission 2 · Label for AI Classify

Our school is training a Smart Recycling Robot. It learns from labels, so every label must be correct.

How to play
  1. Read each item.
  2. Tap Recyclable (paper, plastic, glass, metal) or Compost (food waste).
  3. Label all 10 items, then press Check labels.
Solved!

Mission 3 · Count & Graph Organise

30 students told us their favourite sport. Turn this messy list into a frequency table.

How to play
  1. Pick one sport, for example Football.
  2. Tap every "Football" in the list. Each tap crosses it off.
  3. Type how many you counted in the table. Tally marks appear by themselves.
  4. Do the same for every sport. The total must be 30.
  5. Press Check & draw graph.

Mission 4 · Sort & Filter Use

Here is data about 12 students. Use the table tools to answer 4 case questions.

How to play

  3. Answer each question. If you are wrong, read the hint and try again.
